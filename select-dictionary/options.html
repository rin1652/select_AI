Cài đặt

Bôi đen một câu hỏi trên trang là AI sẽ trả lời ngắn gọn. Để trống API key thì extension tra từ điển như cũ.

Phím tắt

Bấm vào ô phím tắt rồi nhấn tổ hợp mới (cần có Ctrl, Cmd hoặc Alt/Option). Esc để huỷ. Lưu ngay.
